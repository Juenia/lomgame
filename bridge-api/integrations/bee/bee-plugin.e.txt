' 【这个文件是什么】
'   一份可以抄进易语言 IDE 的插件骨架：把 QQ 消息转发给 bridge-api，

'   易语言的 HTTP 与 JSON 能力来自第三方模块（精易模块的 网页_访问S / 类_json，
'   或系统支持库的 HTTP读文件）。我没有你的模块，写死一个就会编译不过，
'   所以这两处只写了"要什么"，具体调用按你的模块补。
'   协议本身（URL、方法、请求头、JSON 字段）在下面写全了。
'
' 【这是没有编译验证过的】
'   本机没有易语言。参数表是按 BeeBot 开发文档「开发实例」抄的；
'   如果你的框架版本参数不同，按实际调（命名对不上会直接编译报错，这一点反而安全）。
'
' 【先验证服务端】
'   在跑 bridge-api 的机器上：
'       node bridge-api/tools/probe.mjs --text ".帮助" --user 20001
'   有回执 = 服务端没问题，剩下的问题都在插件这一侧。
