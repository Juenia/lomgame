## 📖 这是什么

一个跑在群里的**异步文字 RPG**：没有客户端、没有网页、不用下载游戏。

你发一句话，世界回你一段 —— 但底下是一个真的世界：

- 🎭 **你是一个具体的人**：性别、年龄、出生地，属性随经历涨落
- 🛤️ **你会走上一条途径**：从普通人开始，翻线索、找材料、选序列
- 🧠 **你的精神会磨损**：疯狂、污染、消化 —— 这是另一套血条
- 🎒 **你身上带着东西**：行囊有重量、物品有绑定、货币有汇率
- 🌍 **世界不等你**：没人说话的时候，天气在变、势力在动、事件在发生

> 同人作品，非官方。《诡秘之主》版权归爱潜水的乌贼所有。

## 🚀 三分钟上手

**装**：Koishi 控制台 → 插件市场 → 搜索 `koishi-plugin-lom-bridge` → 安装并启用。

**玩**：在群里发

```text
.创建 曾经
.状态
.帮助
```

**菜单每次都会告诉你下一步能做什么，回数字就行，不用背指令。**

## ⚙️ 配置

在 Koishi 控制台的插件配置页里填，全部有默认值 —— **同机部署不需要改任何一项**。

### 内核

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `manageCore` | `true` | 自己拉起游戏内核（装完就能用）；已经在跑的直接复用 |
| `apiBase` | 空 | 外部内核地址。留空 = 自己拉一个 |
| `corePort` | `3201` | 自己拉内核时用的端口（避开 BEE 那边的 3200） |
| `token` | 空 | 与内核的 `BRIDGE_TOKEN` 一致；同机部署留空 |
| `nodePath` | 空 | 用哪个 node 跑内核（留空自动找） |
| `autoInstallNode` | `true` | 本机没有够新的 Node 时自动下载便携版（不装进系统） |
| `nodeDownloadURL` | 空 | 自动安装的下载地址（内网可改成自己的镜像） |
| `dataDir` | 空 | 存档目录（留空用 Koishi 数据目录） |

### 通道

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `platform` | `koishi` | 上游框架名（写进审计与出站回源） |
| `selfId` | 空 | 用哪个 bot 发主动消息（多账号时指定，留空用第一个） |
| `waitSec` | `25` | 出站长轮询挂多久（秒） |
| `declareCapabilities` | `true` | 启动时声明通道能力 |
| `capabilitiesImages` | `true` | 声明能发图 |
| `capabilitiesButtons` | `true` | 声明能摆原生按钮 |
| `inlineUpload` | `true` | 声明能把图上传换公网 URL，换来「图 + 正文 + 按钮」合成一条（只对 QQ 官方通道有意义） |
| `imageFallbackToText` | `true` | 发图失败时退化成发链接，玩家至少不会什么都看不到 |
| `avatarTemplate` | `https://q1.qlogo.cn/g?b=qq&nk={userId}&s={size}` | 头像直链模板。**不填就永远没有头像**，卡面会用名字首字纹章 |
| `blockedGroups` | 空 | 屏蔽的群号，一行一个；`#` 开头当注释。被屏蔽的群不处理指令、也不主动推送，私聊不受影响 |

> QQ 官方通道的头像模板形如 `https://q.qlogo.cn/qqapp/<AppID>/{userId}/{size}`。

## 🎮 玩家能发什么

指令以 `.` 开头，完整表在游戏里发 `.菜单`（图片版）或 `.帮助`。常用的几条：

| 指令 | 说明 |
| --- | --- |
| `.创建 <姓名>` | 建角色，从普通人开始 |
| `.看` / `.走 <地名>` | 看自己在哪、走到别处 |
| `.探索 <地点>` | 找材料（同一地点每日 3 次） |
| `.今日` | 此刻还能做什么 |
| `.状态` / `.角色` | 文字状态卡 / 出图的角色卡 |
| `.背包` / `.使用 <物品>` | 背包与消耗品 |
| `.魔药` / `.服用` / `.晋升` | 调制、服下魔药，再到晋升 |
| `.世界` / `.移动 <城市>` | 天气月相、跨城市移动 |
| `.交易 @玩家` / `.商店` / `.卖` | 交易与买卖 |
| `.队伍` | 组队（上限 4 人） |
| `.遭遇` / `.战斗` / `.挑战 @玩家` | 遭遇、PVE、PVP |
| `.反馈 <内容>` | 提 bug 或建议 |

## 🧩 它到底做了什么

插件只做三件事，别的一概不管：

1. **收到消息** → 原文照送给内核（`POST /api/v1/inbound`）；
2. **长轮询取回执** → 用 `bot.sendMessage` / `bot.sendPrivateMessage` 发出去；
3. **启动时声明能力** → 告诉内核这条通道能不能发图、能不能摆按钮。

玩法判定全在内核里，插件不掺和 —— 所以同一份世界既能接 Koishi，也能接 BEE。

## 🛠️ 自己构建

```bash
cd bridge-api/integrations/koishi
npm install

npm run build       # 编译 src/*.ts → lib/
npm run pack:core   # 把游戏内核打成 core.zip（随插件分发的那份）
npm run prepack     # 上面两步一起做
```

| 目录 | 内容 |
| --- | --- |
| `src/` | 插件源码（TypeScript） |
| `scripts/` | 构建与内核打包脚本 |
| `lib/` `core/` | 构建产物（`npm run build` 生成） |
